# Hosting Jagakali di cPanel dan HiveMQ Docker

1. Upload jagakali-cpanel.zip melalui File Manager cPanel, ke document root jagakali.my.id. Cadangkan website lama jika ada, lalu Extract. Pastikan index.html sejajar dengan dashboard.html. Aktifkan sertifikat HTTPS domain website. Mode DEMO langsung tersedia.
2. Untuk LIVE, gunakan host Linux dengan Docker Compose dan alamat publik yang dapat menerima TCP 80/443. Buat record DNS A mqtt.jagakali.my.id ke alamat publik host Docker. Jika ada record AAAA, arahkan ke IPv6 yang juga dapat dijangkau. Website utama tetap mengarah ke cPanel.
3. Salin seluruh folder deploy/hivemq ke host Docker, termasuk file users yang kosong. Di dalam folder itu buat file .env privat, dengan HIVEMQ_LICENSE_KEY berisi kunci pengganti. Untuk ESP32 tambahkan MQTT_PRIVATE_IP berisi alamat antarmuka LAN/VPN host Docker. Nilai bawaan 127.0.0.1 cocok untuk pengujian dari host saja. Jika nama domain broker berbeda, set BROKER_DOMAIN dan sesuaikan URL WSS di web/dashboard.html sebelum membuat ulang ZIP.
4. Dari folder tersebut jalankan docker compose config --quiet lalu docker compose up -d dan docker compose ps. Untuk diagnosis gunakan docker compose logs --tail=80 https reader hivemq. Port 80 dan 443 perlu tersedia bagi Caddy untuk HTTPS. Compose ini untuk instalasi baru. Jika container HiveMQ lama sudah berisi data, cadangkan konfigurasi dan volume, lalu rencanakan migrasinya sebelum menggunakan port yang sama.
5. Di firmware esp32/jagakali_node/jagakali_node.ino, isi JAGAKALI_MQTT_HOST dengan IP LAN/VPN Docker yang sebenarnya, isi Wi-Fi perangkat, lalu flash node HULU dan HILIR. Batasi akses TCP 1883 pada firewall ke jaringan perangkat tepercaya. Listener perangkat memakai MQTT TCP biasa. Control Center tersedia melalui loopback host pada 8080.
6. Untuk menguji tanpa ESP32, jalankan npm ci di folder mqtt pada host broker lalu node simulator-publisher.js --speed 10. Untuk hasil model, pasang dependensi ai/requirements.txt di mesin Python dan jalankan python ai/server_analisis.py --broker 127.0.0.1 dari root proyek di host broker. Jika proses berada di mesin lain, gunakan IP privat broker pada opsi --broker (untuk simulator gunakan alamat mqtt://IP:1883).
7. Buka https://jagakali.my.id/dashboard.html lalu pilih LIVE. Pastikan indikator MQTT terhubung dan timestamp kedua node bergerak. Dashboard menerima data melalui wss://mqtt.jagakali.my.id/mqtt. Caddy mengurus TLS, dan Mosquitto meneruskan tiga topik baca dari HiveMQ. Akses publik dirancang untuk menampilkan data HULU, HILIR dan analisis. Publikasi perangkat tetap melalui listener privat HiveMQ.

Folder deploy, .env, firmware dan model Python disimpan di luar public_html. Status lisensi dan koneksi ke portal HiveMQ dapat diperiksa setelah broker berjalan. Kunci yang terlihat pada tangkapan layar perlu diganti melalui penyedia lisensi.
